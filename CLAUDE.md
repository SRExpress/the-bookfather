# General guidelines to build the project

# Documentation
- Use hierarchical markdown files
- In markdown files use details/summary sections and more elements that make the reading experience better
- Use mermaid diagrams that are dark/light mode friendly. Select a maximum of 10 colors, and always stick to that. Only borders and edges must be colored. No fill. print friendly for A4 page.

# Code
- All scripts must be without fluff but must be built with SOLID coding principles.
- Code must be well-documented, have exception handling, log (info) messages for all the major functions or events, and log (debug) messages for all minor function calls, and include a logger setting to output logs to stdout and a file.
